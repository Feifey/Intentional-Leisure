Design Decisions
vs. original LLM output (Gemini Prompt 2)
❌ LLM gaveGeneric alternatives. No personalization. No reasoning shown. No escape hatch.
✓ We designedEvery decision below addresses a specific failure in that output.
1
Latency Tolerance
Does the user know it's working?
The 3-second breathing circle isn't loading — it's a designed pause. The LLM's version had zero thinking state; a response appeared from nowhere.
→ breathing circle on phone
2
Capability Discovery
Does a new user know what this can and can't do?
Scope is stated on first launch: "I help you switch from work mode to rest mode. That's all I do." The LLM generated 6+ unrelated concepts with no declared scope.
→ home screen subtitle
3
Transparency
Does the user understand why it said that?
Every suggestion has a visible "because" line citing the user's own profile words. The LLM offered "listen to your acoustic playlist" with zero explanation of why.
→ blue "because" line on each suggestion
4
Trust Calibration
Can the user tell when to trust or verify the output?
"I'll scroll anyway" is never hidden. The user always owns the choice. A gentle re-engagement fires after 6 seconds — not a nag, just a reminder. The LLM had no escape path.
→ escape hatch + gentle follow-up
5
Memory Awareness
Does the user know what the agent remembers or forgets?
The setup screen shows exactly what will be stored before committing. The notification body uses the user's exact words ("before you open Instagram"). The LLM had no memory at all — same generic options every time.
→ setup preview + personalised suggestions
